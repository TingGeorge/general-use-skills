# general-use-skills
Personal skills I use daily.

## Skills

- **[learning-from-resources](skills/learning-from-resources/SKILL.md)** — Turns your study resources (notes, slides, past exam problems) into a complete HTML teaching website so a beginner can score high on the coming exam: 3Blue1Brown-style, diagram-first lessons with meaningful motion, a collapsible left sidebar, practice sections driven by past exams, and English with Traditional Chinese notes on hard concepts. Styled by a bundled design reference ([DESIGNS.md](skills/learning-from-resources/references/DESIGNS.md)), and ends with a check → fix loop.
- **[canvas-showing](skills/canvas-showing/SKILL.md)** — Renders any document (markdown, spec, notes, pasted text) as a single self-contained, editorial-styled HTML page: one page per section, every section turned into pictures (charts, timelines, matrices, keyword-chip maps) where each chip opens its original sentence, top-to-bottom Mermaid diagrams with a zoomable pop-up viewer, and a 原文 panel showing the source lines. Ends with a verify → screenshot → check → fix loop driven by headless Chrome scripts.

Both are manual-invoke only (`/learning-from-resources`, `/canvas-showing`).
