# general-use-skills
Personal skills I use daily.

## Skills

- **[learn](skills/learn/SKILL.md)** — Crash-course tutor: turns a new subject into a beginner-friendly HTML study page aimed at scoring well on an upcoming exam.
- **[canvas-showing](skills/canvas-showing/SKILL.md)** — Renders any document (markdown, spec, notes, pasted text) as a single self-contained, editorial-styled HTML page with a canvas hero, sticky TOC, and auto-generated Mermaid diagrams.

Both are manual-invoke only (`/learn`, `/canvas-showing`).
