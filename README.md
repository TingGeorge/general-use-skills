# general-use-skills
Personal skills I use daily.

## Skills

- **[learn](skills/learn/SKILL.md)** — Crash-course exam tutor in 3b1b style (intuition first, one visual idea per concept, interactive demos): reads the teacher's slides and past exam papers, verifies the math by computer (with a self-check built into the page), and builds one visual, interactive HTML study guide — color-coded chapters, lesson cards, diagrams and demos, KaTeX math, Cursor-style code, mock quizzes and a cheat sheet. English with Traditional Chinese notes on hard concepts. Ships a ready-made template and a finished example.
- **[canvas-showing](skills/canvas-showing/SKILL.md)** — Renders any document (markdown, spec, notes, pasted text) as a single self-contained, editorial-styled HTML page: one page per section, every section turned into pictures (charts, timelines, matrices, keyword-chip maps) where each chip opens its original sentence, top-to-bottom Mermaid diagrams with a zoomable pop-up viewer, and a 原文 panel showing the source lines. Ends with a verify → screenshot → check → fix loop driven by headless Chrome scripts.

Both are manual-invoke only (`/learn`, `/canvas-showing`).
