# Learning from resources

## Task

Create a complete, detailed HTML website guide that is easy to read and easy to understand, so a beginner can get high scores on the coming exam.

## Teaching style

- Use a 3Blue1Brown style: diagram and visualization first, with a light theme.
- Teach complex concepts dynamically, through the web, where that helps. Harder ideas should not rely on diagrams that are too static.
- Use motion only when it is meaningful. If a diagram is only an ordinary figure the reader scrolls past, do not make it dynamic just for effect.

## Language

- The whole tutorial and teaching site is primarily in English.
- For more complex concepts and parts, add a Chinese explanation within the lesson, and use simple examples to explain the harder material.
- All Chinese is Traditional Chinese.

## UI

- Follow the design document [DESIGNS.md](references/DESIGNS.md).
- The site has a left sidebar that is expandable and collapsible.

## Past exam problems

If provided, use the past exam problems the user provides to decide what to emphasize and to build practice sections.

## Check and fix

Check the site, look through it, and verify it. If you find problems, including layout problems or other obvious ones, fix them. Continue until the teaching website and tutorial are perfect.
